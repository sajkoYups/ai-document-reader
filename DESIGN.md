## 1. Brand Identity at a Glance

| Element         | Value                              |
|-----------------|------------------------------------|
| Display font    | Georgia (Serif)                    |
| Body font       | DM Sans (Sans-serif)               |
| Accent font     | DM Mono (use sparingly)            |
| Background      | Near-black `#0a0a0b`               |
| Primary text    | Off-white `#ededef`                |
| Accent colour   | Teal `#2dd4bf`                     |
| Visual tone     | Dark, editorial, precise           |
| Personality     | Authoritative · Calm · Intelligent |

This is a **dark-first brand**. All marketing visuals default to dark backgrounds. Light-background layouts should be used deliberately for contrast moments only — not as a default.

## 2. Core Design Principles

### One headline, one message
Every image must carry a single dominant idea. If someone cannot read your headline in under 2 seconds while scrolling, it is too complex. Remove everything that is not essential.

### The serif leads, the sans-serif supports
Georgia is the brand's editorial voice — authoritative and warm. It carries the primary message. DM Sans handles everything around it. They should never compete; one always defers to the other.

### Size creates hierarchy
The largest element on the canvas is what the eye reads first. Make that choice deliberately. A decorative element that approaches the headline's size will split attention and weaken the message.

### Space is not empty — it's active
Crowded layouts signal desperation. Calm, spacious layouts signal confidence. Give every element room to exist. Padding and breathing space are part of the design, not leftover space.

### Dark backgrounds demand precision
On a dark canvas, every design decision is visible. Misaligned elements, inconsistent spacing, and weak contrast all show immediately. Hold dark layouts to a higher standard of craft.

### Mobile first, always
Over 80% of Instagram is viewed on a phone. Design and review every layout at actual phone scale before exporting. What looks balanced on a 27-inch monitor may collapse on a 390px screen.

## 3. Typography

### Display — Georgia (Serif)

Georgia is a screen-optimised serif with strong, confident letterforms and generous x-height. It communicates trust, editorial quality, and intelligence. Use it to deliver the primary message.

**Use for:**
- Hero headlines on feed posts
- Quote graphics and pull-quotes
- Campaign taglines and brand statements
- Cover slides on carousels

**Never use for:**
- Body copy longer than one sentence
- Text smaller than 28px — Georgia loses its character below this
- Lists, bullets, or structured information
- Text on complex photographic backgrounds without a scrim

> Georgia is a single-weight font. It only renders in Regular. Do not apply Bold — the result is a synthesised, degraded version. Georgia's power comes from scale and spacing alone.

---

### Body — DM Sans (Sans-serif)

DM Sans is clean, modern, and optically balanced at small sizes. It provides contrast to Georgia's warmth and handles all supporting communication.

**Use for:**
- Subheadings and supporting copy
- Carousel body slides with multi-line text
- CTAs and button labels ("Learn more", "Book now")
- Captions, stats, and data callouts
- Any text smaller than 28px

**Weight options:**

| Weight   | Use it for                                   |
|----------|----------------------------------------------|
| Light 300 | Large supporting text alongside Georgia     |
| Regular 400 | Body copy, captions, default text         |
| Medium 500 | Labels, active states, secondary CTAs      |
| SemiBold 600 | Subheadings, emphasis, primary CTAs      |
| Bold 700 | Stats, callout numbers, key data points      |

---

### Accent — DM Mono (Monospace)

Use only when content is explicitly data-driven — percentages, metrics, measurements, or technical values that need to feel precise and factual. One or two words maximum. Never for paragraph text.

## 4. Type Scale

All sizes in **pixels** at 1080px canvas width (Figma or Canva).

| Name         | Size  | Font    | Use in a post                                   |
|--------------|-------|---------|-------------------------------------------------|
| Display XL   | 96px  | Georgia | Single-word or two-word hero headlines          |
| Display L    | 72px  | Georgia | Main headline on a feed post or Story           |
| Display M    | 56px  | Georgia | Headline on carousel cover or quote graphic     |
| Heading      | 40px  | DM Sans SemiBold | Section title on a carousel slide    |
| Subheading   | 28px  | DM Sans Medium | Supporting headline or slide subtitle  |
| Body Large   | 22px  | DM Sans Regular | Lead sentence, intro paragraph        |
| Body         | 18px  | DM Sans Regular | General body copy on carousels        |
| Caption      | 14px  | DM Sans Regular | Fine print, credits, small labels     |
| Data         | 18px  | DM Mono | Metrics, percentages, precise numbers          |

**Minimum sizes by format:**
- Feed post (1080×1080): headline never smaller than **56px**
- Feed post (1080×1350): headline never smaller than **56px**
- Story / Reel (1080×1920): headline never smaller than **72px**

**Line spacing:**

| Text type  | Multiplier | Example at 72px |
|------------|------------|-----------------|
| Display    | 1.1×       | ~79px           |
| Headline   | 1.2×       | ~86px           |
| Body copy  | 1.6×       | (at 18px) ~29px |
| Captions   | 1.4×       | (at 14px) ~20px |

## 5. Spacing System

All spacing is based on an **8px unit**. Every margin, padding, and gap between elements should be a multiple of 8.

| Step | Size  | Use it for                                      |
|------|-------|-------------------------------------------------|
| 1×   | 8px   | Gap between a label and its icon                |
| 2×   | 16px  | Tight internal padding (tags, badges)           |
| 3×   | 24px  | Space between stacked text elements             |
| 4×   | 32px  | Paragraph spacing, card internal padding        |
| 6×   | 48px  | Section separation within a carousel slide      |
| 8×   | 64px  | Safe zone margin from canvas edge               |
| 12×  | 96px  | Large breathing space, hero text vertical offset|

**Canvas edge margins:**
- Feed post: minimum **64px** margin on all sides
- Story: minimum **96px** top and bottom, **64px** left and right
- Carousel: keep all text at least **80px** from the left edge (swipe bleed zone)

## 6. Colour Palette

### Core Colours

| Name           | Hex       | RGB                  | Use it for                              |
|----------------|-----------|----------------------|-----------------------------------------|
| Background     | `#0a0a0b` | 10, 10, 11           | Primary canvas background               |
| Surface        | `#111113` | 17, 17, 19           | Cards, panels, secondary backgrounds    |
| Border         | `#2a2a2e` | 42, 42, 46           | Dividers, frames, subtle outlines       |
| Text Primary   | `#ededef` | 237, 237, 239        | All main text                           |
| Text Secondary | `#8a8a8f` | 138, 138, 143        | Supporting copy, captions, metadata     |
| Text Muted     | `#555559` | 85, 85, 89           | Disabled states, ghost labels           |
| Accent         | `#2dd4bf` | 45, 212, 191         | Highlights, CTAs, underlines            |

### Combining Colours

**Standard dark post:**
Background `#0a0a0b` · Text `#ededef` · Accent `#2dd4bf` (one element only)

**Layered card layout:**
Background `#0a0a0b` · Card `#111113` · Border `#2a2a2e` · Text `#ededef`

**Subdued/supporting slide (carousel):**
Background `#111113` · Text `#8a8a8f` · One key line in `#ededef`

**Accent use rules:**
- One accent element per post — never two
- Use teal to highlight a single word, a CTA, or a key metric
- Never use teal for large blocks of text — it will overwhelm
- Never place teal on `#111113` without testing contrast — it is borderline at small sizes

### Colour to Avoid
- Pure white `#ffffff` — too harsh against the brand's near-black backgrounds
- Pure black `#000000` — slightly colder and flatter than our background tone
- Bright or saturated secondary colours — this is a monochromatic, teal-accented palette; introducing additional hues breaks the system

## 7. Composition & Layout

### Rule of Thirds
Mentally divide the canvas into a 3×3 grid. Place the headline and focal point along the grid lines or at their intersections — not dead centre. Centre-aligned layouts are safe but forgettable. Off-centre compositions feel intentional and editorial.

### Visual Weight
Every element has weight. Large text is heavy. Teal accent elements draw the eye regardless of size. Dark text on dark background is light. Balance the canvas so no single corner or edge feels abandoned.

### Headline Placement
- **Feed posts:** Headline in the upper third or lower third — not the middle. The middle gets lost in the grid thumbnail.
- **Stories:** Centre vertically but keep within the safe zone (96px from top, 96px from bottom — avoid thumb zone and profile area).
- **Carousels:** First slide headline should sit consistently across all slides in a series.

### Hierarchy in Three Steps
Every post should have exactly three levels of visual importance:
1. **Primary** — the headline (largest, highest contrast)
2. **Secondary** — a subheading or supporting line (smaller, secondary text colour)
3. **Tertiary** — caption, date, logo, CTA (smallest, muted or accent)

If an element does not fit into one of these three levels, it does not belong in the layout.

### Negative Space
Dark, empty areas are not wasted canvas — they give the headline room to breathe and create a premium feel. Resist the urge to fill space with decorative elements. If you are adding something to fill space, remove it.

## 8. Text on Images

### On Dark Solid Backgrounds (Preferred)
Use primary text `#ededef` directly. No additional treatment needed. This is the cleanest, most controlled option — default to this whenever possible.

### On Photographs
Photos introduce unpredictable tone variation. Never place text directly on a photo without one of the following treatments:

| Treatment      | When to use                                             |
|----------------|---------------------------------------------------------|
| Dark overlay   | Semi-transparent black layer (60–75% opacity) over the full image |
| Gradient scrim | Black gradient from bottom or top, 80% → 0% opacity    |
| Text panel     | Solid `#0a0a0b` or `#111113` block behind the text only |
| Blur panel     | Frosted/blurred region behind text (use sparingly)     |

Always test contrast after applying. The headline must remain clearly legible.

### On Gradient Backgrounds
If using a gradient (e.g. deep teal to near-black), place text where the background is darkest. Never place light text over the lightest region of the gradient.

### Text Over Texture or Grain
The brand uses a subtle noise/grain texture on dark backgrounds. Text placed over texture must be at minimum `#ededef` — never secondary grey. Muted text disappears against texture.

## 9. Carousel Coherence

A carousel is a single piece of communication spread across multiple slides. It should feel like one thing, not a collection of separate posts.

### Slide Roles

| Slide      | Role                                                       |
|------------|------------------------------------------------------------|
| Slide 1    | Hook — the single reason to swipe. Strong Georgia headline, minimal text. |
| Slides 2–N | Content — one idea per slide. Consistent layout grid.      |
| Last slide | CTA — clear action, brand mark, contact or link.           |

### Visual Consistency Across Slides
- Use the same canvas size on every slide
- Keep the headline text position consistent slide to slide (same vertical zone)
- Use the same font pairing throughout — do not introduce a new typeface mid-carousel
- Carry a single accent element (e.g. a teal rule or highlighted word) through each slide as a visual through-line
- Background depth can vary slightly (e.g. `#0a0a0b` on hero, `#111113` on body slides) but stay within the dark palette

### Swipe Zone
The right 80px of every carousel slide is partially hidden before the user swipes. Keep all meaningful text and graphics at least **80px from the right edge** on every slide except the last.

### Slide Count
- Information carousels: 4–7 slides maximum
- Tutorial or step-by-step: up to 10 slides, but each must contain only one clear idea
- Quote or campaign series: 3–5 slides

## 10. Canvas Sizes

| Format               | Size (px)    | Notes                                        |
|----------------------|--------------|----------------------------------------------|
| Feed post (square)   | 1080 × 1080  | Safe for all placements and grid views       |
| Feed post (portrait) | 1080 × 1350  | More screen real estate — preferred for text |
| Story / Reel cover   | 1080 × 1920  | Keep key content within 1080 × 1420 centre  |
| Carousel slide       | 1080 × 1080  | Must match first slide format exactly        |
| Profile highlight    | 1080 × 1080  | Displayed at 161px circle — keep design simple |

**Export settings:**
- Format: JPG for photography-based posts, PNG for graphics and text-heavy posts
- Resolution: 72ppi is sufficient for Instagram — exporting at higher resolution does not improve display quality
- Colour mode: sRGB
- File size: keep under 8MB per image (Instagram recompresses above this)

## 11. Do and Don't

| Do                                                               | Don't                                                          |
|------------------------------------------------------------------|----------------------------------------------------------------|
| Use Georgia for one strong headline per image                    | Apply bold or heavy weight to Georgia — it will synthesise badly |
| Give every element at least 64px from the canvas edge            | Place meaningful content in the swipe zone (right 80px of carousel slides) |
| Use DM Sans SemiBold or Bold for CTAs                            | Use Georgia below 28px                                         |
| Use the teal accent on one element only per post                 | Introduce new colours outside the defined palette              |
| Apply a dark overlay or scrim before placing text on a photo     | Place text directly on a photograph without contrast treatment |
| Test every layout on an actual phone before exporting            | Use more than three levels of type hierarchy per post          |
| Keep carousel slides visually consistent — same grid, same zones | Design each carousel slide independently without a shared grid |
| Use negative space deliberately — emptiness signals confidence   | Fill empty space with decorative elements to avoid it feeling sparse |
| Keep one idea per slide in a carousel                            | Stack multiple messages or bullet lists on a single post image |
| Export at sRGB, PNG for graphics, JPG for photography            | Export at CMYK — Instagram displays in sRGB only              |
